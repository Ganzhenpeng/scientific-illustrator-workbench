# Third-party dependency

The runtime uses **illustrator-mcp-server 1.10.3** by cyocun (IE3), from
https://github.com/ie3jp/illustrator-mcp-server, pinned to git commit
`57c5c101a5192c61535493f39b653e6f92b8eb29`.
