# 周期双层压电梁项目约定

仅在当前任务明确属于周期双层压电梁、相关动态均匀化或 W–Phi 论文时应用。其他学科、其他用户或普通 Illustrator 任务不继承这些物理选择。若当前用户指令另有要求，以当前任务为准。

## 物理含义与符号

- 当前新图中的电学闭合只使用 `open_circuit`（OC）和 `local_short`（局部短路，SC）。不自行恢复零总电压条件；历史图片中的旧条件也不自动改写。
- 区分 q=0 长波展开与 q=π 带边展开；曲线、图例和图注需保留展开中心、真实阶次以及 OC/SC 的区别。
- 区分无限周期介质的 Bloch 结果与有限结构响应；绘图脚本输出不自动成为数值或物理验证。
- 完整含单位部分的响应 `n_r^alpha` 与 `theta_r^alpha` 的英文术语为 “generalized microfluctuation functions”；`N_r^alpha` 与 `Theta_r^alpha` 为 “microfluctuation functions”。矢量公式资产应保留大小写和上下标。

## 图件与已有文章

编辑已有文章图件时，先读取该项目当前入口和有效清单，用稳定标签或图件身份定位。保留已经批准的物理配色、图例样式、原始数据、误差条、数据缺口和真实方法阶次。不要用示意点补齐缺失数值。

当前中文和英文图文若有双向同步要求，语义核对须覆盖标签、图注和术语；图件编辑不自动授权改写冻结的引言或其他段落。正式图文只包含科学内容，构建过程、哈希、脚本日志和检查清单保留在独立验证文件中。

## 公开示例

本 Skill 可公开的示例应使用合成几何和明确标识的示意内容，不嵌入私人稿件路径、未公开数值、局部应用状态或论文原图。示意梁、波形和场恢复图标只用于展示操作能力，不能被描述为求解或实验结果。
